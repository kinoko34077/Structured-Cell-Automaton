# 📘 SCA (Structured Cell Automaton) GUI

## 🔰 概要

\*\*SCA（構文セル・オートマトン）\*\*は、人間的な言語理解・生成を模倣するための
**進化型セル構文モデル**です。

本プロジェクトでは、そのプロトタイプとして、以下の機能を持つStreamlit GUIアプリを実装しています：

* 構文セルの自動生成（カテゴリ別タグ付与）
* 構文抽出と意味タグ付加
* 意味タグベースの構文交叉・進化
* 構文スコア評価（創造性・多様性・活性度を考慮）
* 発話構文の出力と整形表示
* 内的思考ループの実行と再活性構文生成
* 意味タグの共起ネットワーク可視化
* SID構文系譜ツリーの可視化
* 構文出力のスコアヒートマップ表示

## 📦 ファイル構成

| ファイル                  | 内容                         |
| --------------------- | -------------------------- |
| `sca_gui.py`          | StreamlitによるGUIメインスクリプト    |
| `Cell.py`             | セル（構文単位要素）のクラス定義           |
| `Syntax.py`           | 構文（セル列）のクラス定義              |
| `sca_data.py`         | 多様な構文セル生成関数群（カテゴリ保証あり）     |
| `syntax_extractor.py` | セル系列から構文を抽出するロジック          |
| `scoring.py`          | 構文スコア評価関数（活性・多様性・創造性）      |
| `evolver.py`          | 構文の交叉・変異ロジック（タグベース含む）      |
| `output_zone.py`      | 発話ゾーン（出力構文バッファ）管理          |
| `memory_zone.py`      | 記憶圏（構文の一時保存と再活性）管理         |
| `linearizer.py`       | SID構文を整形して文風に並べる表示器        |
| `visualizer.py`       | Semantic Cluster Map可視化    |
| `genealogy.py`        | SID系譜ツリー（構文進化系統図）可視化       |
| `tag_network.py`      | 意味タグ共起ネットワーク可視化（日本語フォント対応） |
| `scoremap.py`         | スコア出力ヒートマップ可視化             |
| `tagging.py`          | 自然言語からのタグ抽出マッピング処理（初期辞書）   |
| `requirements.txt`    | 必要パッケージ一覧（下記）              |

---

## 💻 起動方法

1. 必要パッケージをインストール

```bash
pip install -r requirements.txt
```

2. Streamlit GUIを起動

```bash
streamlit run sca_gui.py
```
```bash
streamlit run sca_gui_extended.py
```
